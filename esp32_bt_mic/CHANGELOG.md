# VoxTriple Changelog

## v2.2 (current, `ble-hid-keyboard` branch)

### 2026-06-02
- **去除扫描逻辑**：应用只做配置，不扫描/配对设备。系统蓝牙负责连接，应用通过已保存地址直连
- **BLE OTA 固件升级**：0x2A09 特性，应用选 .bin 文件即可无线升级
- 修复：BLE 广播在任意连接后恢复（不再只针对自定义 app）
- 修复：修饰键左右不分（VK 码映射到 HID 修饰位）
- 修复：Python 键盘模拟与 HID 双重输入导致连击（移除 Python 端模拟）
- 修复：广播随机地址导致 Windows 出现重复设备

### 2026-06-01
- **深度睡眠**：30 分钟无按键 → 深睡 ~5µA，GPIO4 唤醒
- **按键唤醒**：连接断开时按任意键触发 BLE 广播 + HFP 重连
- BLE/经典蓝牙同时可用，连接失败 5 秒自动重试
- 设备名缩短：`ESP32_KB_XX` / `ESP32_MIC_XX`
- UI 精简：移除断开/保存/加载/开机自启/配对新设备

### 2026-05-30
- **BLE HID 键盘**：ESP32 模拟蓝牙键盘，不打开应用也能用按键
- SC_BOND 安全配对，耳机连接后触发键盘广播
- 尝试去启动 HFP 自动连接 → 发现跨平台冲突 → 当晚回退
