# VoxTriple 官方独立产品网站 (Official Product & Developer Website)

本工程为 VoxTriple 品牌官方产品展示与固件开发者中心的前端工程。

## 核心设计与对标思考
1. **深度对标 OpenAI Codex Micro**：
   - 深入阐述在 AI 与 Multi-Agent 时代，为什么人类需要专用的物理自然语言输入终端；
   - 相比昂贵且缺失麦克风的桌面大宏板，VoxTriple 创新性地将“全向数字麦克风”与“客制化机械轴体”融为一体，赋予台式机与笔记本随时随地 300 字/分的语音输入能力。
2. **硬件规格全面对齐最新版本**：
   - **尺寸**：`18.5 × 29.8 × 102.0 mm` 极致纤薄机身；
   - **电池**：内置轻薄高能量密度聚合物锂电池，配合低功耗休眠，**日常待机 7 天，重度连续使用支撑 1 整天**；
   - **按键**：客制化机械键盘轴体，PTT 即按即说、松手即停，顺手按回车直发 AI。
3. **互动体验与技术生态**：
   - 掌上虚拟按键映射与上位机串口数据捕获实时模拟器；
   - 20 秒极速有线 OTA 升级演示；
   - Windows/macOS 客户端、固件 bin 与 3D 打印源文件下载矩阵。
