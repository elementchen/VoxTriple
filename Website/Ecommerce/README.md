# VoxTriple 电商产品详情页 (天猫/淘宝旗舰长图流风格)

本工程为 VoxTriple 针对电商（天猫/淘宝旗舰店官方长图、独立站高转化落地页）打造的全新纯白高格调产品详情流。

## 核心设计理念与痛点重塑
1. **纯白极简高级底色**：
   - 彻底摒弃深色/黑色背景，采用类似 Apple 与天猫数码旗舰店的 `#FFFFFF` 与柔和浅冷灰 `#F8F9FB`；
   - 单栏贯通式纵向长图流，从痛点拷问到尺寸工艺层层递进，杜绝东拼西凑感。
2. **深度击穿四大真实痛点**：
   - **台式机无麦克风**：免驱秒连，为强力台式电脑赋予录音棚级发声能力；
   - **AI 对话海量文字输入瓶颈**：键盘打字 70 字/分 vs 语音输入 300 字/分，配合现代 ASR 语音输入法（Win+H / Mac 听写 / 微信键盘），光标处文字极速出字；
   - **拒绝身体被固定**：摆脱桌面麦克风必须正襟危坐低头探身的腰颈酸痛，支持椅背靠仰、漫步口述；
   - **客制化机械轴 PTT**：按住即说，松手即切断，从物理层面杜绝任何误录误开麦。
3. **关键硬件规格纠偏**：
   - **极致纤薄尺寸**：`18.5 × 29.8 × 102.0 mm`，并深度嵌入 CAD 官方实测尺寸工程图（`Website/Medias/aa281c08-59a8-449e-b710-6026e239950d.png`）；
   - **真客制化机械轴体**：清脆段落手感，大拇指实现「按住口述 + 机械回车直发 AI」的极速盲操闭环；
   - **轻薄聚合物锂电池**：告别臃肿的 18650 电芯，配合低功耗休眠，**待机长达 7 天，全天重度连续使用支撑一整天**。
