================================================================================
                    ESP32 蓝牙麦克风项目 - 官方接线图
================================================================================

推荐开发板: ESP32 Lite V1.0.0 (LOLIN32 Lite 兼容版，带 JST-PH 2.0mm 锂电池插座)
麦克风模块: INMP441 全向麦克风模块 (MEMS I2S 数字拾音)
机械按键:   4 × 矮轴客制化按键 (按下拉低至 GND，内部弱上拉)
主机切换:   侧边两档物理拨动开关 (接 GPIO 33 与 GND，内部上拉)
板载指示灯: 物理固化在 GPIO 22 (低电平点亮，无需外部引线)
电池供电:   单节 3.7V 聚合物锂电池 (JST-PH 2.0mm 接口，板载 TP4054 充电芯片)

================================================================================
                    1. INMP441 麦克风接线 (全部集中在左侧排针，连续相邻走线)
================================================================================

    ┌─────────────────────────┐              ┌─────────────────────────┐
    │  ESP32 Lite V1.0.0 (左侧)│              │        INMP441          │
    │                         │              │                         │
    │  3V3     (Pin 2) ───────┼──────────────┼── VDD (⚠️ 严禁接 5V！)  │
    │  GND     (Pin 4) ───────┼──────────────┼── GND                   │
    │  GND     (Pin 4) ───────┼──────────────┼── L/R (接地选择左声道)  │
    │  GPIO 25 (Pin 9) ───────┼──────────────┼── SD  (I2S 串行数据)    │
    │  GPIO 26 (Pin 10) ──────┼──────────────┼── WS  (I2S 声道字选择)  │
    │  GPIO 27 (Pin 11) ──────┼──────────────┼── SCK (I2S 位时钟)      │
    └─────────────────────────┘              └─────────────────────────┘

* 布线优势：3V3、GND、GPIO 25、26、27 在开发板左侧紧密相邻，麦克风排线极短，
  从物理根源上彻底杜绝高频 I2S 信号杂音与飞线干扰！

================================================================================
                    2. 4 × 机械轴体按键接线 (全部连接在右侧排针)
================================================================================

    ┌─────────────────────────┐              ┌─────────────────────────┐
    │  ESP32 Lite V1.0.0 (右侧)│              │        机械按键         │
    │                         │              │                         │
    │  GPIO 4  (Pin 9) ───────┼──────────────┼── Key 1 (PTT语音/RTC唤醒键)
    │  GND     (Pin 1) ───────┼──────────────┼───────┘ (按下接地)     │
    │                         │              │                         │
    │  GPIO 19 (Pin 3) ───────┼──────────────┼── Key 2 (快捷发送键，默认 Enter)
    │  GND     (Pin 1) ───────┼──────────────┼───────┘ (按下接地)     │
    │                         │              │                         │
    │  GPIO 23 (Pin 4) ───────┼──────────────┼── Key 3 (功能上翻键，默认 Up)
    │  GND     (Pin 1) ───────┼──────────────┼───────┘ (按下接地)     │
    │                         │              │                         │
    │  GPIO 18 (Pin 5) ───────┼──────────────┼── Key 4 (功能下翻键，默认 Down)
    │  GND     (Pin 1) ───────┼──────────────┼───────┘ (按下接地)     │
    └─────────────────────────┘              └─────────────────────────┘

* 说明：机械按键采用低电平触发（Active Low），由固件开启内部上拉，接线只需一端接 GPIO，另一端接公共 GND 即可。
* Button 1（GPIO 4）支持 RTC IO 唤醒，在设备进入深睡眠（Deep Sleep）时按下一键瞬时唤醒。

================================================================================
                    3. 两档物理拨动开关 (双电脑主机秒级切换)
================================================================================

    ┌─────────────────────────┐              ┌─────────────────────────┐
    │  ESP32 Lite V1.0.0 (左侧)│              │      两档物理开关       │
    │                         │              │                         │
    │  GPIO 33 (Pin 8) ───────┼──────────────┼── 信号端 (内部弱上拉)   │
    │  GND     (Pin 4) ───────┼──────────────┼── 公共地端 (GND)        │
    └─────────────────────────┘              └─────────────────────────┘

* 开关打到低电平 (GND) -> 激活电脑主机 1 (Slot 0)
* 开关打到高电平 (悬空) -> 激活电脑主机 2 (Slot 1)

================================================================================
                    4. 板载指示灯 (GPIO 22) 与 锂电接口
================================================================================

1. 板载贴片状态指示灯:
   - ESP32 Lite V1.0.0 板载贴片 LED 物理固化连接在 GPIO 22 上。
   - 无需任何外部接线与电阻。
   - 低电平点亮 (Active Low)：
     * 按住 PTT 语音键说话时常亮，松开时自动熄灭。
     * 设备开机/唤醒时快速双闪指示状态。

2. 锂电池接入:
   - 采用标准 JST-PH 2.0mm 2-Pin 反插插座。
   - 适配 3.7V 聚合物锂电池（推荐容量 400 ~ 600mAh 轻薄电池）。
   - 插入 Micro-USB / Type-C 即可由板载 TP4054 线性充电芯片进行自动安全充电。
