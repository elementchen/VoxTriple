# VoxTriple 系统架构 (v2.2)

## 概述

本项目实现了一个基于 ESP32 的蓝牙键盘 + 麦克风系统，包含两个主要组件：
1. **ESP32 固件**：BLE HID 键盘 + 经典蓝牙 HFP 麦克风 + BLE GATT 配置服务
2. **Python 配置应用**：Windows/macOS 桌面应用，用于配置按键映射和设备参数

## 引脚分配 (v2.2)

全部功能引脚集中在 ESP32 NodeMCU-32S **右侧排 (J2)**：

| GPIO | 右排 Pin | 功能 |
|------|---------|------|
| GPIO21 | J2-6 | I2S BCK (位时钟) |
| GPIO22 | J2-3 | I2S WS (字选) |
| GPIO17 | J2-11 | I2S DATA (数据) |
| GPIO4  | J2-13 | Button 1 (深睡唤醒) |
| GPIO16 | J2-12 | Button 2 |
| GPIO19 | J2-8 | Button 3 |
| GPIO23 | J2-2 | Button 4 |
| GPIO18 | J2-9 | LED 指示灯 |

- 3V3: J1-1（唯一左侧引线）
- GND: J2-1, J2-7, J2-19

## 固件升级

| 方式 | 传输 | 速度 |
|------|------|------|
| USB 串口 OTA | UART0 @ 921600 bps | ~12 秒/MB |
| BLE OTA | 0x2A09 特性 | ~3 分钟/MB |

## 电源管理

- 蓝牙 Modem Sleep: ~14mA (正常工作)
- 深度睡眠: ~5µA (30 分钟无操作)
