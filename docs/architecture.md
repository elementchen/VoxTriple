# ESP32 蓝牙麦克风键盘复合系统 - 系统架构 (v1.0.10)

## 概述

本项目实现了一个基于 ESP32 的经典蓝牙 HID 键盘与 HFP 麦克风复合系统，包含两个主要组件：
1. **ESP32 固件**：通过经典蓝牙实现实体 HID 键盘功能与 HFP 免提音频录音，并由代码驱动板载 LED 作反馈。
2. **有线配置客户端 (Win/Mac)**：通过 USB 物理串口与板子直接通信，实现按键自定义映射与极速 20s OTA 升级。

## 蓝牙 Profile 说明

### HFP HF (Hands-Free Profile Hands-Free Client)
* **用途**：ESP32 充当 HFP Client 蓝牙音频录音源向 PC 传输语音。
* **音频格式**：mSBC 宽带语音通道（16kHz 采样率，16-bit 深度，单声道，通过同步 SCO 链路高保真传输）。

### Classic HID Keyboard (Human Interface Device)
* **用途**：免驱虚拟实体蓝牙键盘。
* **主要功能**：四个物理按键按下时，直接发送对应的 USB 标准键盘键值（修饰键 + VK 键值），响应延时达到毫秒级。

### UART SPP 有线有线配置服务
* **用途**：规避蓝牙无故掉线、权限等限制，通过物理 USB 串口进行热改键与 OTA 固件更新，20秒直写稳定无阻抗杂音干扰。

## 数据流

### 音频流
```
INMP441 麦克风 (I2S)
    ↓
[I2S RX DMA] -- 读取 16-bit 单声道 PCM 原始音频 (16kHz 采样)
    ↓
[DSP Audio Processing] -- 滑动平均算法去噪 + 高通滤波滤除工频杂音
    ↓
[Ring Buffer] -- 写入双环形无锁缓冲区
    ↓
[HFP SCO Link] -- 以 7.5ms 的固定帧长度无线发送给电脑
```

### 物理按键与指示灯数据流
```
[Button Pin Input] -- GPIO 4/18/19/23 四向独立硬件输入
    ↓
[Hardware Interrupt / Task Debounce] -- 软件多路消抖处理
    ↓
[Key Mapper & Indicator] -- 触发 HID 发送键值 + 将 GPIO 22 (板载LED) 拉低 (0) 发光指示
```

## 硬件连接表

### 开发板型号：ESP32 Lite V1.0.0 (LOLIN32 Lite 兼容版)

| 开发板引脚 | 外设引脚 | 功能 | 说明 |
| :--- | :--- | :--- | :--- |
| **3V3** (左侧排 Pin 2) | **VDD** | INMP441 供电正极 | ⚠️ 严禁接 5V，会导致麦克风烧毁 |
| **GND** (左侧排 Pin 4) | **GND / L/R** | INMP441 地 / 声道接地 | 麦克风共地并配置为左声道采集 |
| **GPIO 25** (左侧排 Pin 9) | **SD** | I2S 串行数据输入 | 音频数据输入到 ESP32 |
| **GPIO 26** (左侧排 Pin 10) | **WS** | I2S 帧字选 (LRCLK) | 16kHz 帧同步时钟 |
| **GPIO 27** (左侧排 Pin 11) | **SCK** | I2S 位时钟 (BCLK) | 传输位数据时钟同步 |
| **GPIO 33** (左侧排 Pin 8) | **Switch** | 双主机物理切换开关 | 低电平: Slot 0 (PC 1) / 高电平: Slot 1 (PC 2) |
| **GPIO 4** (右侧排 Pin 9) | **Button 1** | PTT 语音 / 唤醒物理键 | 支持 RTC GPIO 深度睡眠唤醒，默认映射 `RCtrl` |
| **GPIO 19** (右侧排 Pin 3) | **Button 2** | 快捷操作发送键 | 配合代码自定义改键，默认映射 `Enter` |
| **GPIO 23** (右侧排 Pin 4) | **Button 3** | 功能上翻键 | 配合代码自定义改键，默认映射 `Up` |
| **GPIO 18** (右侧排 Pin 5) | **Button 4** | 功能下翻键 / 配对擦除 | 默认映射 `Down`，长按 3 秒清除配对并重启 |
| **GPIO 22** (板载内部固化) | **Onboard LED** | 板载状态指示灯 | 低电平有效 (0:亮, 1:灭)，无需外接电阻 |
| **JST-PH 2.0mm** (板载插座) | **BAT** | 3.7V 聚合物锂电池 | 支持 Micro-USB / Type-C 通过板载 TP4054 充电 |
