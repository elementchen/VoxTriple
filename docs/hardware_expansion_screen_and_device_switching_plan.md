## 一、项目目标与需求梳理

### 1.1 核心需求
1. **多设备切换能力（Multi-Host Seamless Switching）**：
   - 实现 ESP32 经典蓝牙（HID 键盘 + HFP 麦克风）在两台主力设备（如 Windows 工作站 与 MacBook 笔记本）之间的一键快速切换。
   - 彻底解决两台电脑同时在场时的蓝牙射频抢占、互相打断问题。
2. **增加 3.0 英寸长条形彩色 LCD 屏幕（NV3007 驱动）**：
   - 驱动规格：NV3007 控制器，8 引脚封装，4-Wire SPI 接口，分辨率典型为 142×428 像素。
   - 显示内容：实时显示当前活跃主机（Win / Mac 图标）、蓝牙连接状态、PTT 录音波形动效、按键键值提示、电池电量等。
   - 能耗协同：支持屏幕背光独立控制与低功耗休眠（熄屏休眠与按键唤醒点亮）。

## 二、硬件选型与引脚分配矩阵 (Pinout Matrix)

### 2.1 当前 ESP32 Lite V1.0.0 引脚使用现状
当前系统已占用的引脚：
- **音频采集 (INMP441 I2S)**：`GPIO 25` (SD/DATA), `GPIO 26` (WS), `GPIO 27` (SCK/BCK)
- **物理按键 (4 路输入)**：`GPIO 4` (Button 1 / PTT / RTC 唤醒), `GPIO 19` (Button 2), `GPIO 23` (Button 3), `GPIO 18` (Button 4)
- **板载指示灯**：`GPIO 22` (Active Low LED)
- **系统通信与烧录**：`GPIO 1` (TXD0), `GPIO 3` (RXD0)

### 2.2 NV3007 8-Pin 条形屏接口定义与接线规划
8 引脚长条屏（4-Wire SPI）典型引脚定义如下：
| 屏幕引脚序号 | 丝印标识 | 功能说明 | ESP32 Lite V1.0.0 推荐连接引脚 | 物理排针位置 |
| :--- | :--- | :--- | :--- | :--- |
| **Pin 1** | **GND** | 电源地 | **GND** | 右侧排 Pin 1 或左侧 Pin 4 |
| **Pin 2** | **VCC** | 电源正极 (3.3V) | **3V3** | 左侧排 Pin 2 |
| **Pin 3** | **SCL / SCK** | SPI 时钟总线 | **GPIO 14** (HSPI SCK) | 左侧排 Pin 12 |
| **Pin 4** | **SDA / MOSI**| SPI 数据总线 | **GPIO 13** (HSPI MOSI) | 右侧排 Pin 13 |
| **Pin 5** | **RES / RST** | 硬件复位引脚 | **GPIO 15** | 右侧排 Pin 12 |
| **Pin 6** | **DC** | 数据/命令选择 | **GPIO 16** | 右侧排 Pin 8 |
| **Pin 7** | **CS** | SPI 片选使能 | **GPIO 17** | 右侧排 Pin 7 |
| **Pin 8** | **BLK / LED** | 背光控制引脚 | **GPIO 5** (支持 PWM 调光) | 右侧排 Pin 6 |

> **引脚选定设计考量**：
> 1. **避开芯片 Strapping 风险引脚**：GPIO 0 (Boot)、GPIO 2、GPIO 12 (MTDI 闪存电压检测) 全部避开，确保上电 100% 正常启动，绝不卡 Bootloader。
> 2. **硬件 SPI 极速刷新**：选用 ESP32 硬件 HSPI 控制器，SPI 时钟频率可达 40MHz~80MHz，保证 142×428 细腻色彩无撕裂流畅渲染。
> 3. **背光节能管理**：BLK 接 GPIO 5，系统闲置时可渐变熄灭背光，进入深度休眠时彻底断电关闭背光。

### 2.3 多设备切换开关的硬件接入方案（二选一评估）

#### 【方案 A：独立双档拨动开关（推荐，硬件级明确指示）】
- **硬件形态**：三脚双档拨动开关（Slide Switch：ON-ON）。
- **接线方案**：
  - 中间公共脚：接 **GPIO 34**（左侧排 Pin 5，纯输入引脚）。
  - 一侧挡位：接地（GND），代表 **Slot 0 (Windows)**。
  - 另一侧挡位：接 3.3V（或悬空+外拉电阻），代表 **Slot 1 (Mac)**。
- **优点**：
  - **充分利用输入专用引脚**：`GPIO 34` / `GPIO 35` 属于 ESP32 内部无法作为输出的引脚，用来做开关状态检测是最极致的资源利用，完全不浪费宝贵的输出引脚！
  - **物理所见即所得**：开关拨到左边就是电脑 A，拨到右边就是电脑 B，开机即按开关位置决定连接对象，没有任何误触和记忆负担。

#### 【方案 B：复用现有按键组合键 / 长按切换（零硬件追加）】
- **实现方式**：例如双击 Button 4，或同时长按 Button 2 + Button 3 持续 2 秒触发切换。
- **优点**：无需外加任何开关元件与开孔。
- **缺点**：缺少物理挡位指示，必须依赖屏幕亮起才能确认当前处于哪个设备。

## 三、NV3007 屏幕驱动与图形渲染架构

### 3.1 显存消耗评估与优化策略
- **全屏显存大小**：
  $142 \times 428 \times 2\text{ bytes} \approx 121.5\text{ KB}$。
- **RAM 挑战**：
  ESP32 片上 DRAM 在经典蓝牙 + HFP 音频 + WiFi 栈开启后，剩余连续堆内存通常在 100KB~130KB 左右。若开辟全尺寸 FrameBuffer，会导致内存临界告警。
- **架构方案：SPI DMA 双行缓冲 (Line/Tile DMA Buffering)**：
  - 建立两块仅有 $142 \times 32$ 像素的 DMA Ping-Pong 缓冲区（每块仅消耗 $9\text{ KB}$，总共仅 $18\text{ KB}$）。
  - 渲染任务在 CPU 核心 1 进行几何与文字排版，SPI 外设在后台通过 DMA 异步推流到屏幕。
  - **效果**：不仅节省了 100KB 以上的珍贵 RAM，还能实现超过 30 FPS 的无抖动平滑刷新。

### 3.2 UI 界面视觉布局规划 (142 × 428 竖屏/横屏模式)

长条屏的长宽比非常接近现代智能灵动条，非常适合打造极具科技感的桌面生产力工具界面：

## 四、双主机多设备无缝切换状态机设计

### 4.1 槽位模型（Dual-Host Slot Model）
NVS 存储结构维护两个独立槽位：
- **Slot 0**：绑定的设备 A（例如 Windows），保存其 MAC 地址、LinkKey 及设备名。
- **Slot 1**：绑定的设备 B（例如 macOS），保存其 MAC 地址、LinkKey 及设备名。
- **Active Slot**：当前活跃槽位指示。

### 4.2 极速切换时序（Active Handover Protocol）
当用户拨动开关或按下切换快捷键时，固件执行如下受控切换流程：
1. **静默断开当前链路**：
   向当前主机发送优雅断开（`esp_bt_hid_device_disconnect()` 和 `esp_hf_client_disconnect()`），耗时约 50ms。
2. **切换内部活跃上下文**：
   切换 `active_slot` 索引，更新白名单地址。
3. **定向主动呼叫目标主机（Active Page）**：
   从端 ESP32 直接向目标主机发起主动呼叫（`esp_bt_hid_device_connect(target_addr)`）。
   - 由于目标主机蓝牙始终处于开启状态，主动呼叫可在 **1.0 ~ 1.5 秒内** 瞬间完成链路重聚与加密握手！
4. **屏幕联动刷新**：
   屏幕顶部图标由 Windows 蓝旗平滑过渡切换为 Apple 银标，提示“已连接 MacBook”。
