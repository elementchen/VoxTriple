## 二、产品全景定位与核心痛点

### 1. 核心定位
**VoxTriple** —— 专为**台式机电脑（普遍无内置麦克风）**与 **AI 对话交互（海量日常 Prompt 输入需求）**打造的随身手持式语音输入机械终端。

### 2. 用户痛点与解决方案
- **台式机无麦痛点**：绝大多数台式机用户没有内置麦克风或需要佩戴笨重耳麦。VoxTriple 免驱即连，随手拿起即说。
- **AI 时代海量 Prompt 疲劳**：打字速度瓶颈（50~80字/分），配合 Windows（Win+H）/ macOS（听写）原生语音识别，出字速度高达 **200~300 字/分钟**，生产力提升 300%。
- **对标哲学**：深度对标 **Codex 极简生产力哲学**、**Work Louder** 机械质感与 **Apple** 纯白高级美学。

## 三、硬件与固件核心参数共识

1. **外观三围与便携性**：
   - 净尺寸：`18.5 × 29.8 × 102.0 mm`（纤巧圆润，手感比口红更便携，支持盲操握持）。
2. **机械按键手感**：
   - 4 × 客制化机械键盘轴体（段落轴/静音轴触感），支持 PTT（Push-To-Talk 按住说话、松开静音）及快捷回车发送。
3. **声学拾音规范（文案与对外术语）**：
   - **禁止使用的低端术语**：不要对外暴露“INMP441 芯片型号”等冰冷电子料号。
   - **推荐规范术语**：*“声学微孔导音仓”*、*“指向性抗噪拾音腔体”*、*“防喷麦结构设计”*。
4. **电池与续航**：
   - 采用轻薄聚合物锂电池（摒弃笨重粗大的 18650 电池，保证极致便携）。
   - **续航表现**：**待机长达 7 天，持续高强度使用支撑 1 整天**。
5. **无线与连接协议**：
   - 经典蓝牙 HID + HFP 免驱动双模复合设备，无缝兼容 Windows、macOS 与 Linux。

- **技术栈**：零构建体系（Modern HTML5 + Tailwind CSS CDN + Lucide Icons + 原生 ES6+），无需安装 npm 依赖，开箱即开浏览器浏览。
- **双子站点结构**：
  1. `Website/Ecommerce/`：纯白背景、无边框高级质感的大图流长图页，直击痛点，专为快速决策与转化设计。

  3. `Website/Medias/`：共享媒体物料（CAD工程图、3D 渲染图、实拍尺寸图等）。
